# EvolveLab 项目定位

## 它是什么

EvolveLab 是一个源码开放、非商业许可的项目，用来研究 Coding Agent 的三个核心问题：

1. 怎么让 Agent 的行为过程可观测，而不是只看最终结果
2. 怎么让 Agent 在扩展工具能力时仍然可控
3. 怎么给文件修改和命令执行加上安全边界

所以它更适合被理解为一个**研究型工程项目**，而不是成熟的终端用户产品。

## 它重点关注什么

- ReAct 循环的实现与控制
- Thought -> Action -> Observation 的可视化
- 运行时工具注册与持久化
- 围绕代码修改设计的 Git 快照、验证与回滚
- 命令执行和文件操作的沙箱与限制

## 它不是什么

- 不是 Cursor、Codex、Claude Code 的替代品
- 不是低门槛、面向所有开发者的通用代码助手
- 不是已经验证真实高频使用或商业化价值的成熟产品

## 它更适合什么场景

- 学习 Coding Agent 的基本运行机制
- 调试 Agent 为什么失败、卡住或走偏
- 研究工具系统设计与安全边界
- 作为 Agent / DevTools / AI Infra 岗位的系统设计展示项目

## 当前边界

- 上手和理解门槛都比较高
- 更适合探索和阅读源码，不太适合作为日常高频工作流工具
- 目前强项在架构和安全思考，而不是产品成熟度

## 为什么会有这个项目

黑盒的 Coding Agent 很有用，但会隐藏太多关键信息：

- 为什么会走这一步
- 为什么某个工具调用失败
- 为什么任务卡住了
- 一次错误修改之后怎么安全恢复

EvolveLab 的意义，就是把这些原本被隐藏的取舍和问题，尽量变成可见、可分析、可工程化处理的东西。
