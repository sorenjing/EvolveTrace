# EvolveTrace 项目定位

EvolveTrace 解决 Coding Agent “最终 diff 可见，但执行过程难审查、风险往往在执行后才被发现”的问题。它把 Codex Hooks 暴露的任务、工具、权限、失败和验证事件保存为本地工程记录，并通过时间线和证据面板帮助开发者定位需要追问的步骤。

项目现在同时提供一层窄而可验证的本地 Safety Sentinel：对于磁盘格式化、物理磁盘写入、越出项目边界的递归删除和远程脚本直灌 shell 等高置信度风险，它在 Codex PreToolUse 阶段返回拒绝；每一次拒绝仍保存为脱敏审计证据。

项目刻意保持窄边界：不执行 Agent、不调用额外 LLM、不展示隐藏思维链、不上传源代码。风险与阻断均来自可测试的确定性规则。它是本地 Guardrail，不是完整沙箱，也不声称覆盖所有工具路径。

当前版本面向个人开发者和本地工作流。仓库提供可回放 fixture、自动化测试和无需真实 Codex 的演示；在 ChatGPT 桌面版中可通过内置 Browser 打开本地审查页面，但尚未宣称团队协作、跨 Agent 兼容或大规模性能指标。
